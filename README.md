# DeepSeek 时段收费显示插件

## 这是什么 / 谁在用 / 怎么开始

在桌面端 Windows 标题栏居中显示当日峰谷计费时段、当前时段高亮、下一跳倒计时，第二行是余额与 tokens 用量。
想知道「现在是不是双倍价」「我这账号一共烧了多少 token」的桌面端用户用它。
第一步：装上，**重启一次 DSH 桌面端**（Host 路由要加载），标题栏就出现卡片。

## 安装

包名 `@local/dsh-tariff-titlebar`，本地目录安装（PowerShell；路径含 `'`，bash 单引号会断开）：

```powershell
dsh plugin --profile desktop add "%USERPROFILE%\Documents\deepseek-harness\default-workspace\plugins\dsh-tariff-titlebar"
```

- 命令转发给 profile 里的 pnpm，本地目录记成 `link:C:/...`；装完**自动追加进** `~/.dsh/profiles/desktop/package.json` 的 `dsh.profile.bundles`。
- **但本插件有 Host 半侧**（`index.js` 注册 `/dsh-tariff/account-usage`，`inject: ["webServer","deepseekAccount"]`）：首次安装或改过 `index.js` 后必须**重启一次 DSH 桌面端**，光刷新页面不够；之后改 `client.js` 刷新页面即可（HMR）。
- 验收两条：① 标题栏出现峰谷卡片；② `GET http://127.0.0.1:<GUI端口>/dsh-tariff/account-usage` 返回 `{"ok":true,...}`，或 `{"ok":false,"error":"not signed in"}`（后者=没登录账号，属正常，不影响峰谷显示）。

## 怎么用

- **位置**：`shell.overlay`，order 10，靠 `--dsh-windows-titlebar-height` 铺满标题栏并居中；**只在 `html[data-windows-titlebar]` 下显示**——用普通浏览器打开 Web GUI 看不到。
- **上排**：五个时段胶囊（00–09 空闲、09–12 高峰、12–14 空闲、14–18 高峰、18–24 空闲），高峰金色、当前时段更深底 + 同色描边并带「时间 · 计费阶段」。
- **收起/展开**：上排最右小箭头 `︿`／`﹀`，收起态单行约 22px，状态存 `localStorage` 的 `dsh.tariffTitlebar.collapsed.v2`。
- **倒计时**：右侧独立胶囊带时钟图标，每秒刷新、精确到秒，会跳过周末与法定节假日，指向下一个真正的高峰开始/结束；切到高峰琥珀色、切到空闲绿色。
- **第二行**：余额胶囊（`remote.account.getBalance`，进页面 / 窗口聚焦 / 每 60 秒刷新；≥¥10 紫、¥5–10 蓝、¥1–5 琥珀、<¥1 红）+ 蓝色用量胶囊（Host 路由按 31 天窗口从 2023-01-01 回溯汇总账号历史 tokens，内存缓存 10 分钟；Host 桥不可用时退回会话累计 tokens，标签变「会话用量」）+ 说明胶囊。
- **看精确数字**：鼠标在余额/用量胶囊上停约 0.9 秒弹出，移开即消失。
- **前提**：余额与账号用量需要 DSH 登录账号；只有 API Key、未登录时余额胶囊不显示，其余照常。

## 配置

- `cordis.patch.yml`：一条 insert（`id: tariff-titlebar` / `name: '@local/dsh-tariff-titlebar'`），**无其它字段**。
- **无 config / 无 UI 配置项**，可调的都是代码常量：
  - `client.js`：`SEGMENTS`（五个时段边界）、`HOLIDAY_RANGES`（2026 法定节假日，2027 公布后追加）、`COLLAPSED_KEY`（收起状态键名）、余额色阶阈值。
  - `index.js`：`CACHE_MS = 10 分钟`、`CONCURRENCY = 5`、`WINDOW_SECONDS = 31 天`、`HISTORY_START = 2023-01-01`、单请求超时 `25s`。
- 停用：profile 的 `cordis.patch.yml` 里给该行加 `disabled: true`。

## 已知限制 / 不在这里放什么

- **不含密钥**：不读、不存 `sk-` API Key；平台授权 token 与 Cookie 只在 Host 进程内使用，不下发浏览器。
- **不写死账号数据**：余额、用量都是实时取（内存缓存 10 分钟，无落盘文件）；仓库里没有账号信息。
- **节假日表只到 2026**：2027 年安排公布前，2027 的节假日会按普通工作日/周末算。
- **只在桌面端标题栏显示**：浏览器 Web GUI 里看不到，不是缺陷。
- **改 `index.js` 必须重启一次桌面端**，F5 不够（Host 路由在进程启动时注册）。
- 窗口变窄时依次省略倒计时、品牌文字、非当前时段；窄于 820px 隐藏说明胶囊（余额与用量保留）。
- 账号用量回溯依赖平台接口，接口本身单次最多 31 天，历史很长时首次汇总偏慢（有 10 分钟缓存兜着）。

## 原文档（保留）

在桌面端窗口顶部（Windows 标题栏）居中显示 DeepSeek 当日的峰谷收费时段：五个时段常驻展示，高峰时段着金色、当前时段高亮并带「时间 · 计费阶段」文字，右侧是下一次切换的倒计时；第二行依次是余额胶囊、账号用量胶囊和计费规则说明胶囊。

## 计费口径

依据 DeepSeek 官方[模型 & 价格](https://api-docs.deepseek.com/zh-cn/quick_start/pricing/)：

> 空闲时段价格为高峰时段价格的一半。北京时间周一至周五（不含中国法定节假日）9:00 - 12:00、14:00 - 18:00 为高峰时段；其余时段，包括周末及中国法定节假日全天均为空闲时段。

所以「高峰 = 花费 ×2」只在工作日高峰成立：

| 时段 | 计费 |
| --- | --- |
| 工作日 09:00-12:00、14:00-18:00（法定节假日除外） | 高峰 |
| 工作日其余时间 | 空闲（高峰价 5 折） |
| 周末、法定节假日全天 | 空闲（高峰价 5 折） |

- 所有时间按**北京时间**（UTC+8）计算，与官方价格页一致
- 内置 2026 年中国法定节假日表；2027 年安排公布后可在 `client.js` 的 `HOLIDAY_RANGES` 追加
- 非工作日或节假日不点亮金色高峰胶囊，整天空闲；倒计时会跨过周末/节假日，指向下一个真正的高峰开始或结束时刻
- 账号用量胶囊上长悬停约 0.9 秒可看到精确数字；移开即隐藏

说明胶囊按当前时段显示：

- 空闲时段：「当前为空闲时段」+「token 按正常价格计算」（含工作日平峰、周末与节假日全天）
- 高峰时段：「当前为高峰时段」+「token 按双倍价格计算」

配色规则：

- **品牌「峰谷」**：金色渐变胶囊 + 黑色文字/金色金币，不再使用黑色胶囊
- **上排时段**：按时段计费状态着色——空闲时段为绿色胶囊，高峰时段为黄色胶囊；周末与法定节假日全天空闲，所以五个胶囊全是绿色。当前时段的胶囊用更深底色 + 同色描边，并把「时间 · 空闲时段/高峰时段」放进同一个胶囊里
- **倒计时**：右侧倒计时装进独立胶囊并带小时钟图标，颜色跟随切换目标——切到高峰用琥珀色、切到空闲用绿色；精确到秒，例如「18 小时 37 分钟 24 秒后切换到高峰时段」「45 分钟 10 秒后切换到空闲时段」，每秒刷新一次
- **第二行**：最左侧为余额胶囊；紧挨着右侧是蓝色「用量」胶囊（当前会话累计 tokens）；再右侧是一个青绿色（teal）外层大胶囊（1px 内边距 + 明显边框，能看出是把两个小胶囊包在一起），内部再分两个独立胶囊——空闲时「当前为空闲时段：」用绿色胶囊（末尾带冒号，高峰时切换为琥珀色），以及浅蓝色「token 按正常价格/双倍价格计算」
- **居中**：整个卡片放在铺满标题栏高度的居中座里（flex 水平/垂直居中），窗口变窄时自动保持居中，不再依赖 transform；`max-width: calc(100vw - 16px)` 防止溢出

## 账号余额

- 第二行左侧的紫色「余额」胶囊读取当前 DeepSeek 账号的可用余额（充值余额 + 赠金余额），金额按 ¥/$ 两位小数显示（数值 13px、标签 12px）；悬停可看充值/赠金明细
- 余额胶囊会按金额动态换色（人民币阈值；美元按更小的等比例阈值）：
  - ≥ ¥10：紫色（保留原配色，正常）
  - ¥5–10：蓝色（开始留意）
  - ¥1–5：琥珀色（偏低）
  - < ¥1：红色（紧张）
- 数据来自 Host 的账户服务（`remote.account.getBalance`），进入页面、窗口重新获得焦点时刷新，之后每 60 秒刷新一次
- 未登录账号、只有 API Key，或读取失败时不显示该胶囊，不影响峰谷时段显示
- 该胶囊只显示金额，不会把余额写入对话或发送给模型

## Tokens 用量

- 余额右侧的蓝色胶囊优先显示**账号累计 tokens（全部历史）**，包含 DSH 之外的调用；Host 侧使用 DSH 当前登录授权访问平台用量接口，不读取、不保存 `sk-` API Key
- 平台接口单次最多查 31 天，Host 会从 2023-01-01 起按 31 天窗口回溯并汇总；结果缓存 10 分钟，进入页面、窗口聚焦时刷新
- 如果 Host 桥接不可用（例如更新后还没重启 DSH），会自动退回显示**当前会话累计 tokens**（和输入框上方统计同源），标签从「账号用量」变成「会话用量」
- 数值较大时用中文单位缩写：`1.4万`、`1.1亿`、`1.2万亿`；小于 1 万时显示完整分组数字
- 鼠标在胶囊上停留约 0.9 秒，会弹出精确数字，例如「账号累计共 1,063,337,720 tokens（全部历史）」；移开鼠标立即消失
- 数据来源：Host 路由 `/dsh-tariff/account-usage` 通过 `deepseekAccount.getPlatformSession()` 取得平台授权并调用 `api/v0/usage/by_api_key/amount`；授权 token 和 Cookie 只在 Host 进程内使用，不会下发到浏览器
- 会话兜底数据通过隐藏的 `conversation.composer.dock` 条目读取 `tokenUsage` 投影，不占输入框空间

## 收起与展开

- 上排最右侧有一个小箭头按钮：展开态显示 `︿`，点击后卡片收起成单行胶囊（品牌胶囊 + 当前时段胶囊，胶囊内仍带「时间 · 计费阶段」），箭头变成 `﹀`；再点一次展开回完整两行
- 收起后的高度约 22px，只占标题栏一半，方便平时不占视觉空间
- 收起状态保存在 `localStorage` 的 `dsh.tariffTitlebar.collapsed.v2`，刷新或重启后保持上次选择
- 收起时余额、用量、说明胶囊、其他时段和倒计时暂时隐藏

## 插件结构

| 文件 | 作用 |
| --- | --- |
| `package.json` | 组合包清单：`dsh.bundle.patch` 与 `dsh.client`（Web、`immediately`、注入顺序） |
| `cordis.patch.yml` | 插入 Loader 行 `tariff-titlebar` |
| `index.js` | Host 半侧：注册只读路由 `/dsh-tariff/account-usage`，用 DSH 登录授权按 31 天窗口汇总平台账号全部 tokens；授权只在 Host 内使用 |
| `client.js` | 浏览器半侧：注册 `shell.overlay` 标题栏槽位和隐藏的 `conversation.composer.dock` 用量桥接；纯 `react`/`react/jsx-runtime` 渲染；含北京时间、周末与节假日判定、账号余额轮询和 tokens 用量格式化 |
| `locale/zh.json`、`locale/en.json` | 插件管理器展示用标题与描述 |
| `icon.svg` | 原创金币 + 峰谷折线图标 |

界面只使用主题 token（`--dsw-alias-*`、`--dsw-static-amber-*` 等）与 DSH 调色板里的青绿色，自动适配明暗主题；仅在 `html[data-windows-titlebar]` 下显示，因此普通浏览器打开 Web GUI 时不会遮挡内容。窗口变窄时依次省略倒计时、品牌文字、非当前时段；窄于 820px 时隐藏说明胶囊（余额与用量胶囊保留）。

## 停用

在 profile 的 `cordis.patch.yml` 中停用该行，或在插件页关闭该组合包：

```yaml
- id: tariff-titlebar
  disabled: true
```

> 账号累计用量由 Host 半侧提供。更新了 `index.js` 或首次安装后，需要**重启一次 DSH 桌面端**（只刷新页面不够）才能加载 Host 路由；之后改 `client.js` 仍可热更新。
